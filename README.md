# Zorbit

**🇬🇧 English** | **🇫🇷 Français**

---

## 🇬🇧 English

**Zorbit** is a 2D pixel-art platformer — my first ever video game!

I built it from scratch using **Godot 4** and **GDScript**. Halfway through the project, I started using Claude (Anthropic's AI) to help me learn game development concepts, fix bugs, and improve my code.

### Features
- 3 handcrafted levels with increasing difficulty
- Dash ability unlocked by a mysterious old NPC
- Checkpoints and lives system
- Bronze / Silver / Gold medals per level
- Multiple enemy types (bats, caterpillar, chomper...)
- Controller required (Xbox recommended)

### Controls
| Action | Button |
|---|---|
| Move | Left stick |
| Jump | A |
| Dash | RB |
| Interact | X |
| Pause | Start |

### Built with
- [Godot 4](https://godotengine.org/)
- GDScript
- Kenney asset packs
